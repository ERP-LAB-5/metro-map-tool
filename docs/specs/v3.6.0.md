# metro-map-tool v3.6.0 — Export a part, navigate with room

> **Status:** Frozen
> **Released:** 2026-09-15
> **Previous release:** v3.5.2
> **Template:** python-tool-template v0.4.1 (unchanged)

## Goals

- Share one key area or one period of a busy map without editing a copy of it.
- Give navigation the whole screen, and let the person steer the zoom and the board.

## Big picture

Maps now carry swimlanes and phases. Exporting everything is still the default, but the export can
be cut down to the chosen lanes and phases. Navigation already follows the ride; now it also gets
out of the way of the map.

## Features

### Export chosen swimlanes and phases (designer, renderer, CLI, MCP)

**What:** Export SVG asks which swimlanes and which phases go in the file. All are ticked by
default. The file holds only what is chosen.

**Details:**
- The cut is made on the spec before rendering, never on the picture
  ([ADR 0014](../adr/0014-a-cut-is-made-on-the-spec.md)).
  - Stations and junctions outside the chosen lanes' rows, or outside the chosen phases'
    dates, are left out.
  - Lanes that were not chosen close up, so the chosen ones stack.
  - The ruler covers only the chosen phases.
  - Lines, branches, zones, interchanges, notes and rides keep what is left.
  - A line cut short at one end runs on past the edge of the map.
- The dialog only appears when the map has swimlanes or phases; otherwise Export saves straight
  away, as before.
- `/api/render` takes `cut: {"swimlanes": [...], "phases": [...]}`. Leaving a list out means all.
- On the command line, `metro-map spec.json --lane NAME --phase NAME` (both repeatable).
- The MCP tool `render_map` takes `swimlanes` and `phases`.
- The map itself is not changed, and neither are uncut renders.

**Acceptance criteria:**
- [x] All lanes and phases chosen (the default) gives exactly the same SVG as before.
- [x] One lane gives only that lane's stations, with the other lanes closed up.
- [x] One phase gives only the stations in its dates, with the ruler covering that phase.
- [x] An unknown lane or phase name is refused with a sentence.
- [x] Tests pin these.

### Navigation hides the panel (designer)

**What:** Starting navigation folds the side panel away. Stopping puts it back as it was.

**Acceptance criteria:**
- [x] Panel open → start → folded; stop → open again.
- [x] Switching from one ride to another does not flash the panel back.
- [x] Your own panel preference is not overwritten.

### Zoom while navigating (designer)

**What:** The mouse wheel, the toolbar zoom and `+`/`−` change the navigation zoom and keep
following the ride; before, the wheel stopped following. The zoom range is 0.5×–8×, and the
slider follows whatever changed it.

**Acceptance criteria:**
- [x] The wheel zooms and the camera keeps following.
- [x] The slider shows the zoom set by wheel or keys.

### Minimise and maximise the navigation board (designer)

**What:** A button on the board (and the `M` key) collapses it to one line: ride, now/next stop,
play and exit. Pressing it again brings the full board back. The choice is remembered in this
browser.

**Acceptance criteria:**
- [x] Minimised, the board shows the current stop and keeps updating.
- [x] The state survives stopping and starting navigation, and a reload.

## Open questions

## Dependencies and risks

- The cut changes rows and columns in a copy of the spec. Rides whose start, end or via is cut
  away are left out of the file.

## Decisions

- ADR 0014: a cut is made on the spec, not the picture.
